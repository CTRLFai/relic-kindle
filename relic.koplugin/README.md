# relic.koplugin

The Relic plugin for KOReader. Copy this whole folder into `koreader/plugins/` on the Kindle; the folder name must stay `relic.koplugin`. What Relic is, how to install it and how updates work: see the README and SETUP.md at the root of the repo.

## Where things are

Rules are plain Lua with no KOReader dependency, so the tests in `tools/tests/` run them under LuaJIT on a desktop. Screens are KOReader widgets.

**Screens**
- `main.lua`: every screen, button and menu, plus the plugin entry point
- `console.lua`: drawing helpers for both themes (Console and Beam Me Up)
- `meditate.lua`: full-screen countdown for Meditate and Pomodoro
- `lockscreen.lua`: draws the lock screen image and takes over the screensaver

**Rules**
- `game.lua`: quests, XP, levels and ranks, Daily Directive and streaks, gold and loot, baking, exploration, save migrations
- `combat.lua`: turn-based fights
- `gear.lua`: gear slots, bases, rarities and affixes
- `recipes.lua`: the baking recipe book (found by experimenting)
- `skills.lua`: skills, which appear as you earn them
- `route.lua`: the 83 Via Francigena stages and map geometry (generated)

**Story** (spoilers: don't open these if you want to be surprised)
- `story.lua`: the story engine, which turns game events into scenes and keeps the logs you can reread
- `story_act1.lua`, `story_act2.lua`: the story text

**Sync and upkeep** (all optional, all Todoist except the updater)
- `inbox.lua`: pulls quests, loot and step counts from your Todoist project "Relic"
- `backup.lua`: daily save backup, 7 rotating copies, restore from Tools > Relic
- `chronicle.lua`: one line per finished quest; feeds the Records page and a monthly backup
- `status.lua`: a daily plain-text status report
- `updater.lua`: the self-updater (see "Updates" in the root README)

**Data**
- `manifest.lua`: version number and file list with SHA-256 hashes, checked by the updater (generated by `tools/make_manifest.py`)
- `fonts/`, `map/`, `sprites/`, `gear_art/`: fonts (licenses inside), map images, monster sprites and gear engravings

Your save lives outside this folder, in `koreader/settings/relic_state.lua`, so updating or replacing the plugin never touches it.
